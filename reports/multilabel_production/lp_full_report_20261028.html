Can one model report every lens class at once?

A single image model was asked to report every LP class visible in a lens picture, including the case where nothing is wrong. 1,248 pictures were held back and never seen during training. Average precision asks how well the model ranks pictures: line the pictures up by how sure the model is, and are the true ones near the top. It runs from 0 to 1, where 1 is perfect and 0.5 is a coin toss. Accuracy is not used, because most pictures are normal and a model that always says "nothing wrong" would look excellent and be useless.

5. Why each LP class scored as it did

Only the classes with at least twenty test pictures are explained. The four rare ones are shown above but cannot support a conclusion either way.

  • Missing Primary Package. The most consistent LP class in the set and the largest test group. The model ranks it almost perfectly and still finds 98.6 percent of the pictures at the default cut-off.
  • No Lens. An empty cavity looks different from every other case. Ranking is almost perfect; recall at the default cut-off is lower than it could be, and the best balance is reached at a lower one.
  • Multiple Lens. A large, visually distinct class. Strong ranking and a balanced precision and recall, so the number is trustworthy.
  • Cavity Off Center. Only 37 test pictures, but the shift of the cavity is a strong visual cue and the model separates it well.
  • Low Dose. Meets its target, with a caveat: the annotation of this class was left unfinished, so some pictures that carry it may never have been marked. At the default cut-off it finds very few, and its best balance, 0.73, comes at a lower one.
  • Lens Off Center. Below its target. The lens position also changes with multiple lens and cavity offset, so the three overlap; the model ranks it moderately and its best balance is 0.71.
  • Dirty Camera. Below its target, and the shape of the error is unusual: when the model says dirty camera it is always right, but at the default cut-off it finds only 3 percent of them. Dirt on the camera is diffuse and low contrast, and the test group is small. The best balance, 0.60, comes at a much lower cut-off, so this is partly a cut-off problem and partly a data problem.
  • Folded Lens. The weakest of the classes with enough pictures to judge. Almost every folded lens in the data also carries multiple lens, so the model learns the pairing rather than the fold itself and then fails on the few folded lenses that appear alone. Its best balance is 0.36 at a lower cut-off. This is a labelling finding before it is a training one.

6. The thirteenth class: one OOI flag

Run 2 adds a single answer that covers all eight OOI classes together. It is not a new finding and it does not say which OOI class is present; it says that at least one is, which is what the routing step needs to decide whether a picture goes on to the object stage.

Because it routes rather than describes, it is judged by how often it fires, not by average precision.

This is the behaviour the routing step needs: it rarely mistakes a clean picture for a dirty one. It does miss about one OOI picture in six, which is the safer direction, because a missed OOI sends a picture to manual review rather than letting it through.

7. What this tells us

Four findings, each carrying the number that supports it.

  • Four LP classes are effectively solved. Missing Primary Package 1.00, No Lens 0.99, Multiple Lens 0.97 and Cavity Off Center 0.94.
  • Three LP classes hold the average down, for different reasons. Folded Lens 0.27 is a labelling problem, Dirty Camera 0.58 is mostly a cut-off problem, and Lens Off Center 0.75 overlaps with two other classes.
  • Folded Lens needs a data decision before more training. Almost every folded lens also carries multiple lens, so there is little in the pictures to separate the two. Marking folded lenses that appear alone, or reporting the pair as one class, would move this number more than a longer run.
  • Dirty Camera is visible to the model but scored too cautiously. Everything it flags is right, and at a lower cut-off its balance rises from 0.06 to 0.60.

8. What we would do next

In order, each tied to a finding above.

  1. Run the planned second experiment with class weighting and compare it with this one, to see whether Folded Lens and Dirty Camera move.
  2. Report Folded Lens and Multiple Lens at a lower cut-off, or as one class, and state which reading is meant whenever the number is quoted.
  3. Repeat the measurement on the newly annotated pictures, so each class rests on more examples before any threshold is fixed for production.
