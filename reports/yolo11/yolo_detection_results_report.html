How to read the three numbers. mAP measures how well the model finds a defect AND puts the right label on it. The next two are easily confused, so read them separately:

Matched IoU (tightness). For the boxes the model finds, how closely does each box hug the true defect? This is the "is our box located well" question. Higher IoU = the extracted box is more trustworthy for downstream use (for example cropping for a classifier).

Match rate (coverage). Of all true defects, how many get a detected box at all? This is the "did we even find it" question. A higher match rate means more defects are found; it does NOT mean the boxes are tighter.

note Our match rate uses a lenient definition: a defect counts as found if a same-class detected box overlaps it at all at confidence 0.25 (even near-zero overlap). It is not "found with IoU of 0.5 or more". A stricter "usable extraction" figure (share of defects with a box at IoU ≥ 0.5) would be lower. This distinction is covered in section 4.

Honest framing. This report shows measured evidence. It does not assert that YOLO is "better" at any one thing; it gives the numbers so the discussion is grounded. The current bottleneck is not box quality but detection coverage: match rate of 32-41% means roughly a third to two-fifths of true defects are detected at confidence 0.25. IoU on the boxes we find is healthy.

Setup (identical for every run)

Ten object-of-interest defect classes. 346 training / 88 held-out images, fixed stratified split and seed, 100 epochs, 640 px input, and the same labels throughout.

Batch size note: the primary baseline row is the batch 8 run. An earlier batch 16 run of the same baseline sits beside the architecture variants. mAP is near-identical across the two batches (0.2745 vs 0.2729); IoU differs within run-to-run spread (0.597 vs 0.568), so comparisons are cleanest within a batch group, and the batch-8 group is the anchor.

Reading this group. The position matters, the layer type matters less. The same plain two-layer edit that was flat at the deepest position gives mAP50 0.3096 (+0.037 over this baseline, the best mAP in the whole study set) and IoU 0.583 (+0.015) when placed at the mid-resolution position. At the deepest position, plain or residual makes little difference and does not beat baseline on mAP. Probable reason, inline: these defects are small and route through the mid-resolution features; the deepest map is too coarse for them.

4. The answer for the discussion

Box location quality (IoU) is good for the boxes the model finds. Competitive variants land at a matched IoU of 0.58-0.61, meaning a detected box overlaps its true defect by well over half, on average. That supports using these boxes confidently for cropping and downstream classification.

The current limit is how many defects are found, not how well they are located. Match rate of 32-41% means many true defects get no box at confidence 0.25. Improving recall (finding more boxes) is the higher-leverage direction for raising both mAP and usable extraction coverage.

One caution on small classes. A few defect classes have very few examples in the held-out set (2-3 images each), so their individual numbers are noisy and should not be over-read. Pooled results above are the stable signal.
