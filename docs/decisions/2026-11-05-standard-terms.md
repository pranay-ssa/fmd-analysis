# Standard terms in reader-facing work

Reader-facing work uses the field's standard terms. A plain-language substitute is not a
simplification when it replaces a term the reader already knows.

- Use train, validation and test; threshold; AUPRC; macro F1; exact match; inference time per
  picture.
- Do not invent "teach", "tune", "cut", "lens score", "average class score", "fully right" or "time
  per picture".
- If a genuinely new term is needed, define it in one line where it first appears.
- The rule covers slide faces, table headers, bullets, footnotes, speaker notes, workbook labels,
  commentary and messages.
