## Workbook revision after the review

The first build used "Objects" and "Conditions". The review replaced those names: OOI tags for
boxed objects, Lens Presentation for the whole-image tags. The rebuild also carries the guide
code on every row, lists all 15 lens presentation and 8 OOI classes including the four with no
annotated pictures (P1_EBC, P1_TL, P1_LR, P1_SG at 0), marks the legacy classes (HEMA
Obstruction P2_HMO, Bubble On 123, Bubble On Edge), and adds an OOI tag analysis for the 24
files: 2,089 pictures with at least one OOI tag, 36,098 tags, and the tags-per-picture
distribution. OOI statistics come from `experiments/multilabel_edge/ooi_stats.py`; the
verifier now checks the 15 and 8 guide rows, the zero rows and the distribution as well as the
counts.

measurement.

## Correction: EDA and split read the gate differently

The rule was restated: in the EDA a picture belongs to its class whenever it shows the class,
and the micron-gate tag is only the subset ("of which size-flagged"); the split keeps the
frozen gate-only positives for the four gated classes. The total-EDA workbook now follows
that split of readings: class counts and tag combinations use all class pictures, the split
sheet uses the gate positives. The 147 pictures outside the split are 62 legacy-only (no
guide class) and 85 with an un-gated object only (counted in their class in the EDA). The
0-class-label row is 62, not 147. A v8 split built on class positives was discarded; v6 and
v7 remain the split of record.
