# Week 47

## What was asked

Two things on 16 November, in order. First, whether a CNN can see the micron size cut at all: a
pilot on the four classes that carry a size flag. Second, once the lead confirmed the rule order,
the redo of Experiment 1 with that order and with size decided by the flag.

The rule order arrived as a message: primary is Clear, Bubble and untagged pictures of the four
flagged classes pass, everything else fails; secondary is the same with Bubble Cluster moved to the
pass side, kept as the traditional position but presented second. The user corrected one framing:
Experiment 1 already counted both orders, so what changed is which number leads, plus one genuinely
new piece of arithmetic, the gate truth for the four classes.

## Experiment 3.1 - can the model see size

The frozen split could not answer it: its test set holds 3 decisive Foreign Matter pictures and 0
for the other three. A derived split moved every picture with no size flag out of training and
validation into test, 4,964 / 1,058 / 1,533, with 85 decisive pictures added from outside the frozen
split.

Stage 0 scored the Experiment 1 checkpoint first. Its score falls as the defect grows, and it fails
84.5% of below-cut Foreign Matter pictures. Two size-trained arms followed, 224 and 448 pixels:

- `gate4_224`: Foreign Matter AUROC 0.745 against 0.613, false-fire 49.5% against 84.5%, recall
  83.5% against 93.7%. Fiber 0.687 against 0.572.
- `gate4_448`: AUROC 0.759, recall 43.0%, false-fire 12.4%. Fewer good pictures failed, more real
  defects missed; the ranking did not improve, the threshold moved.

The size-bin curve is the result to keep: the old model's mean score falls with box size, 0.792 at
8-12 pixels to 0.554 at 36-64; the gate arm rises across the cut at about 19.5 native pixels, 0.445
to 0.556. No pre-registered bars were set; the pilot is a placeholder judged by the lead.

Housekeeping on the way: the nine kanban cards were archived and the work moved to two subagents
and direct SSH. The reason was worker deaths on a credential with no fallback provider, not the work
itself.

## Experiment 3.2 - the redo

Option B: two specialists, one verdict. The condition model reads twelve lens columns plus Bubble,
Bubble Cluster and Wet Package on the frozen assignment, so lens results land on the same pictures
as Experiment 1. The size specialist is `gate4_224`. A picture fails if either fires.

On the 1,121 shared test pictures:

| Rule | Fail | Caught | Missed | Pass | Passed | Wrongly failed |
|---|---|---|---|---|---|---|
| Primary, Cluster fails | 784 | 778 (99.2%) | 6 | 337 | 311 (92.3%) | 26 |
| Secondary, Cluster passes | 766 | 760 (99.2%) | 6 | 355 | 325 (91.5%) | 30 |

Decomposition: the Experiment 1 reading applied to the same two models gives 768 fail and 353 pass,
exactly the earlier number. The size correction is worth 2 pictures; the new order 18, all Bubble
Cluster.

Condition model: macro AP 0.8017 over fifteen columns, per-class AUROC 0.931 to 1.000. Weak by F1:
Folded Lens 0.578 at precision 0.480, Wet Package 0.517, Bubble Cluster 0.682 at precision 0.533.

## What is open

- Which rule order is the working rule. The difference is 18 pictures, all Bubble Cluster.
- One run per model; no repeat-seed comparison on this line yet.
- Bubble Scatter has one test picture; its F1 is noise.
- HEMA has 6 untagged test pictures, so its size read says little.
- `gate4_448`'s recall is a threshold choice; no sweep was run.
