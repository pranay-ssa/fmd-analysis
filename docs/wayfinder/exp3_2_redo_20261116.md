# Experiment 3.2

## Destination

Redo Experiment 1 on the same test pictures with the pass/fail rule in the order the client and lead
now use, and with the size of the four gated classes decided by the size flag rather than by the
object being present. Report every class, not only Foreign Matter.

The rule itself is recorded in `docs/decisions/2026-11-16-size-rule-order-and-gate-truth.md`. That
file is the authority for the two rule ids; this file is the run that applied them.

## Design: two specialists, one verdict

Option B was chosen over one nineteen-column head. A picture cannot sit in training for its lens
tag and at the same time be an unseen picture for its size class, so the work is split:

- **Condition model.** Twelve lens columns plus Bubble, Bubble Cluster and Wet Package. Fifteen
  outputs. Trained on the frozen 70/15/15 picture assignment, so the lens results are measured on
  exactly the pictures Experiment 1 used.
- **Size model.** The four gated classes, from Experiment 3.1. Trained on flagged pictures only,
  tested on untagged pictures with a tagged guard.

A picture fails if either model fires a failing label. It passes only when neither does. A picture
with several labels takes the strictest outcome.

| Label present in truth | Primary rule | Secondary rule |
|---|---|---|
| Clear only | pass | pass |
| Bubble only | pass | pass |
| Bubble Cluster | fail | pass |
| Any of the twelve lens conditions | fail | fail |
| Wet Package | fail | fail |
| A size-flagged class below the cut, untagged | pass | pass |
| A size-flagged class above the cut | fail | fail |

The assignment is the frozen one, carried over for comparability. The condition table was rebuilt
from the annotation rather than copied from an Experiment 1 artifact; the moves were proved by
`build_labels_conditions.py` asserting the split counts. The size split is Experiment 3.1's, where
327 pictures left train or validation because they carry no size flag.

Test populations: the pass/fail verdict is on the 1,121 pictures that are test for both models, the
same population Experiment 1 was scored on. The size read is on the 1,533.

Recipe on both: ResNet50, batch 8, 50 epochs, SGD 1e-4 momentum 0.9 Nesterov, seed 42, inverse
frequency weighting on the training split, threshold per class by maximum validation F1.

The condition run printed a traceback after writing every artifact, from a missing key in its
closing print. The exit code is non-zero; no artifact is affected. Its record is
`run/exp3_2_cond15_20261116/run.json`.

## Result

On the 1,121 shared test pictures:

| Rule | Fail pictures | Caught | Missed | Pass pictures | Passed | Wrongly failed |
|---|---|---|---|---|---|---|
| Primary, Bubble Cluster fails | 784 | 778 (99.2%) | 6 | 337 | 311 (92.3%) | 26 (7.7%) |
| Secondary, Bubble Cluster passes | 766 | 760 (99.2%) | 6 | 355 | 325 (91.5%) | 30 (8.5%) |

Decomposition against Experiment 1, measured with the same two models so only the arithmetic moves:

| Reading | Fail | Pass |
|---|---|---|
| Object present is enough to fail, the Experiment 1 reading | 768 | 353 |
| Size correction applied, secondary order | 766 | 355 |
| Size correction and the new order | 784 | 337 |

The 768 reproduces the Experiment 1 number exactly. The size correction is worth 2 pictures. The
order is worth 18, all Bubble Cluster.

Drivers: under the primary rule the Bubble Cluster column fires on 18 of the 26 wrongly failed
pictures, on its own in 7. Under the secondary rule the Foreign Matter size call fires on 19 of the
30, on its own in 14. The six misses are 2 Cavity Off Center, 2 Lens Off Center, 1 Bubble Scatter,
and 1 Bubble Cluster or one Fiber size picture depending on the rule.

Condition model, all fifteen classes, 1,121 pictures: AUROC 0.931 to 1.000. F1 at the chosen cut
0.000 to 0.991; the weak ones are Folded Lens 0.578 at precision 0.480, Wet Package 0.517, Bubble
Cluster 0.682 at precision 0.533. Bubble Scatter has one test picture.

Size model at its chosen cuts, on the test pictures carrying each class: Foreign Matter AUROC 0.745,
precision 0.260, recall 0.835; Fiber 0.687 / 0.839 / 0.589; Extraneous Polymer 0.879 / 1.000 / 0.375;
HEMA 0.974 / 1.000 / 0.846 on 6 untagged pictures.

## Verification

- `verify_exp3_2_workbook.py` recomputes both rules from the 2,242 per-picture rows, checks the
  fifteen condition supports and all per-class counts against the tables the models trained from,
  and sweeps every sheet for internal names. It exits 0 on the delivered workbook.
- The 768 starting point was recomputed by running the same two models against class truth, not
  copied from Experiment 1.
- One AUROC was recomputed by hand from the predictions: Missing Primary Package 1.000, matching.

## Open

- Which rule order is the working rule. The two differ by 18 pictures, all Bubble Cluster; nothing
  else changes between them.
- One run per model. The 18-picture gap is smaller than the seed band measured elsewhere, so the
  difference between the two rules should be read as a statement about the rule, not about the
  models.
- Bubble Scatter has one test picture; its F1 is not a result.
- HEMA has 6 untagged test pictures. Its high scores rest on pictures like those it trained on, so
  they do not show that it reads size.
